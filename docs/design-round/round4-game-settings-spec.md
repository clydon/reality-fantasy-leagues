# Changing a game later: page spec (Round 4)

## The job

A game's settings answer, for whoever runs it: how is my game set up, what can I still change, what's fixed and why, and how do I
stop it. They're the same game's screen as Start a game made it, with the rules as lines, value first, but now with the state the
game is in: what's locked this episode, what the draft fixed, what's over.

People:
- **Conor** runs three games and tinkers. He opens one game's settings from the game itself to start one more player each week, and
  checks this episode's lock before Sunday.
- **Andrew** runs one game he started in two taps. He never comes here unless someone asks him to let a friend in.
- **A Game admin** (Riley in the lineup game) reads the settings and opens or closes this episode's lock for a couch that sat down
  late. Nothing else is hers to change.

Ways in:
- **The game's page**, its ⋯ menu: "Game settings", for whoever runs it. It's the main way in, because people think of a game, not of
  Backstage.
- **Backstage › Game settings**: the games you run here, one row each.
- **A line in Recent changes** opens that game's settings.

## A game's settings (a new screen, pushed over the game or Backstage)

| # | Block | Holds |
| --- | --- | --- |
| 1 | **The title card** | The game's name over the show's art (Start a game's TitleCard); under it "You run this" or "Game admin: you can open or close this episode's lock" |
| 2 | **This episode's lock** (games with lineups or picks) | Today's lock row, first because it's the one thing with a deadline: "Episode 6's lineups: Open · locks Sun 8 PM", Auto or Override |
| 3 | **The rules**, a line each, value first | Tap a line and its control opens under it; a fixed one says why and opens nothing |
| 3a | How moves lock | "Together" or "At your own pace" (Start a game's two cards). Together opens one choice: late moves on the honour system (open until you've watched it or the next airs) or none (everything locks at airtime). At your own pace is fixed: "Chosen when the game started" |
| 3b | Who scores each week · On the bench (a lineup) | The steppers, "from Episode 6; nobody loses points already scored"; the bench fixed once the draft starts: "Set at the draft" |
| 3c | Team size (a draft) | Fixed once the draft starts: "Set at the draft" |
| 3d | The questions (a sheet) | The checklist, until the game starts |
| 3e | Who can join | The choices, Recommended marked |
| 3f | How long | "Episode 1 to the season's end"; the end's picker |
| 3g | Replacing people who leave | The Waivers page |
| 4 | **Stop this game** | Archive (Undo) and Delete (held, restorable for 30 days), this game only |

Every change saves at once, with Undo on the toast and a line in Recent changes. A changed line keeps its dot and "Reset to
recommended" (as today).

## The drill tree

| Level | Questions brought to it | Holds today | Verdict |
| --- | --- | --- | --- |
| Backstage › Game settings | Which game; what's set | Every game's every setting, stacked | **Restructure**: a list, a row each |
| A game's settings | What's set, what I can change | A block in the stack | **New screen**: the game's own, from its page |
| This episode's lock | Is it open; can I override | The lock row | **Keep**: it works; moves to the top of the game's screen |
| How moves lock | Can I change it | Two radio tiles in the engine's words; own pace as prose | **Restructure**: Start a game's two cards, the late-moves choice under Together |
| A rule | What it is, can I change it | Headed blocks of radios and steppers, always open | **Restructure**: a line, value first, its control opened in place |
| A fixed rule | Why can't I change it | "Set at the draft", inline | **Keep** the words, as a line without a chevron |
| Stop this game | How do I end it | Archive or delete, at the page's foot, for any game | **Repaint**: on the game's own screen, for that game |

## Spoilers

None of these settings tells a result. A finished game's row says it's finished only when it's over at your mark (the archive's
rule, Round 3).
