# Tonight content contract

2026-11-10. Replaces the insufficient compact-only pass. The user has asked to review Tonight before any theme is extended to other pages.

Tonight is a situation-aware overview. It does not reproduce the full episode recap, game tables, cast-stat podiums, every optional game, planning invitations and a grid of all games. Those destinations stay available through named actions and the established tabs.

| Situation | First mobile view | Detail destination |
| --- | --- | --- |
| Watching, behind | Personal next episode; Watch along; I watched it; friends' numbered progress; current-episode chat/reaction; optional game invitation | Clock; progress confirmation; episode-specific conversation; game discovery |
| Playing live | Next airing; every typical required decision; summarized saved choices; watching/planning; friends; compact last-episode result | Move editors; full saved team/card; individual game page and opponent decisions; full episode recap |
| Playing at own pace | Personal next episode; Pick → Watch → Reveal; necessary decisions; whose progress differs; last revealed result | Pick/stats comparison; watch clock; explicit reveal; game history through that episode |
| Watching an older season | Personal progress and next episode; same complete watching/social actions; no broadcast deadline | Episode history and companion |
| Solo play | Next personal decision; own streak/progress; no meaningless first-of-one rank | Personal history and optional social invitation |
| Caught up, still airing | Waiting for the next airing; plan/remind; last watched episode chat and reaction | Schedule; episode history; optional games. Never a completed-season state |

At 390×844, the primary actions, progress context and social entry must be visible together. At 360×700, the essential watch/decision controls and friend-progress entry must fit; optional discovery can continue below. Controls retain at least 44px targets and body copy stays readable. No fixed-height clipping is used to make a capture look complete.

Intent determines these content branches and return paths. Impeccable carries the show's real artwork, bold condensed type, angled first-action plate and expressive reaction imagery. PFD requirements R1–R5 in [the derivation](perception-first.md) determine grouping and order: personal situation, next action, social payoff, then depth. These are design hypotheses, not measured user outcomes.

The review uses recorded local Survivor 49 facts and engine scores, with explicit scenario fixtures for participation, progress and friend marks. Local sample choices never write to the app. Older-progress views filter episode events and scores to their scenario mark; later results are not part of their displayed payload. The selector belongs to the review board, not to product navigation.
