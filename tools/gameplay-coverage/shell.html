Source support, compiled specimens and verified UI are separate. An unchecked cell is unfinished work, even when its game compiles.

Start with a capability

Select a row or UI cell to see its data contract, stress cases, compiled examples and exact evidence still needed.

The complete normalized specimen corpus is available in the generated JSON report. Compiler examples are not captured UI fixtures.

No new game constraints are enforced by this tool. Profile recipes require actual Atlas adapters/fixtures before they can be verified. Passing evidence must name the renderer, specimen, profile, subcase, viewport and theme, and reference saved artifacts.

Pairwise samples expose observed combinations; they do not prove all possible valid combinations, higher-order interactions, usable layouts or user approval.
